# RO2612025-01 — what changed, and why it could not be read before

## The two dialects

| | RO2611976-01 | RO2612025-01 |
| --- | --- | --- |
| channel names | one `\|CP` field, `7,32,<name>` repeated | one `\|CN` block per channel |
| sample width | float32 | **float64** |
| sample interval | one `\|CD` for the file | one `\|CD` per channel |
| header length | ~250 bytes | hundreds of kB |

`eis_local.FamosFile` now dispatches on what the file contains and returns a
`FamosV1` or a `FamosV2`. Nothing downstream knows which it was handed.

## Two things that made the obvious fix wrong

**The v1 reader does not raise on a v2 file.** It regexes for four keys and a
v2 header contains strings matching all four — just not with the meaning v1
assumes. Handed one of these recordings it returns, without complaint:

    names      []                 (nothing matched `7,32,`)
    n_ch       12                 (read out of |CR's calibration field)
    fs         0.0625 Hz          (a per-channel |CD, not the file's)

So a dispatcher cannot use "did it throw" as its test, which is what the
original adapter did. `_famos_plausible` asks instead whether the parse means
anything — names present, count matching, a believable acquisition rate, at
least one segment channel — and the dispatcher tries the other dialect when it
does not.

**A fixed comma count finds the data offset wrong.** `|CS,<ver>,<bytes>,` is
followed by the samples, but the number of leading fields is not the same
across writers, and a `0x2C` byte inside a float64 sample is indistinguishable
from a delimiter. One comma too many lands *inside* the data. Measured on a
written-to-order v2 file: 20,000 samples read back as 19,998, every channel
shifted.

`|CS` declares how many bytes follow, so the offset is now **checked** — the
right one is where the bytes remaining equal the bytes declared — and the file
records which basis was used and whether it was confirmed.

## Verified against bytes, not against a description

`make_synth_famos.write_v2()` emits the v2 layout, and
`test_famos_dialects.py` round-trips every channel at both widths, asserts the
offset is confirmed, and asserts the silent-v1-failure above so nobody
re-introduces the exception-driven dispatch.

Placeholder files — campaign folders carry 0-byte entries for cards that were
never connected — are refused by name rather than parsed into a card with no
channels.
